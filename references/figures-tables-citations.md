# 图表分工、文献与终审自检（Figures, Tables & Citations）

## 1. 图、表、正文的分工原则

| 载体 | 核心职责 | 禁忌 |
|---|---|---|
| **图（Figures）** | 展示趋势、空间分布、对比格局、过程变化与变量关系 | 同一图面跨图重复；图内文字与曲线/柱条碰撞；图注缺少统计口径或单位 |
| **表（Tables）** | 保存精确数值、输入参数、样本信息、分组统计与敏感性检验结果 | 把表格当成正文复述的复制品；列名含义模糊或缺少单位 |
| **正文（Text）** | 提炼决定性模式、关键定量锚点、组间比较、机理解释与边界 | 逐行把表里所有数字重念一遍；用文字描述替代图表中应有的精确对比 |

- **图文一致性**：正文描述的线型、颜色、子图编号、坐标范围、统计口径（如全模型单元数占比 vs 体积占比、整体集合 vs 典型切片）必须与实际嵌入的图件和表格完全一致。
- **图注自明性**：图注应独立交代图件展示的对象、关键指标符号、单位及统计范围（例如近场范围、加权方式、判定阈值）。

---

## 2. 符号、单位与统计口径规范

1. **全篇单一映射**：同一物理量/统计量全篇固定同一符号与单位，避免符号冲突（例如若偏转角差已用 $D$，刚度矩阵应改用 $C$ 而非 $D$）。
2. **首次出现即定义**：任何缩写、符号或指标首次在正文出现时，必须给出中文全称、物理含义与单位。
3. **样本与分母透明**：报告百分比或计数时，必须明确分母是什么（如“占模型单元总数的 39.3%，按体积计占 8.06%”“48 组尝试中 47 组满足条件”）。
4. **区分数据层级**：明确区分“原始观测/实测资料”“受控数值模拟输出”“解析分解推论”与“未验证外推”。

## 3. 文献与引文规范

1. **学术来源硬门槛**：
   - 只引用**正式学术期刊论文、学术专著或国际权威学术会议论文**；
   - 严禁将软件操作手册、在线帮助网页、未核实的网络博文作为正式参考文献（涉及软件底层算法或经验公式时，应追溯至其原始理论期刊论文）。
2. **真实性与实引核对**：
   - 每条参考文献必须在正文有实际引用，且引文支撑的论点与原文献内容一致；
   - 核对作者、题名、期刊名、年份、卷期、页码及 DOI（若该文献有官方勘误，需一并核实并说明）；
   - **严禁编造文献、虚构卷期页码或凭记忆拼写文献信息**。
3. **格式规范**（按目标期刊参数配置）：
   - 正文数字引文通常采用顺序编码上标（如 `[1]`、`[2,3]`），文末按首次出现顺序编号；
   - 若投递要求双语著录的中文期刊（如《岩土力学》《石油学报》），所有中文参考文献须补齐对应的英文题名与作者拼音/英文著录。

## 4. 提交前终审自检清单（Checklist）

- [ ] **主线闭环**：引言提出的问题、方法定义的指标、结果展示的证据、结论收束的答案是否完全同序且一一对应？
- [ ] **可读性**：全文是否已消除生造黑话、代码翻译腔、长括号堆叠与 AI 目的性前缀？
- [ ] **正向与克制**：是否消除了不必要的“不是……而是……”负向立论？结论是否未超越正文证据强度？
- [ ] **图、表、文对应**：正文是否没有逐行复述表格？正文提到的图号、子图标签、数值是否与当前最终图表逐一吻合？
- [ ] **文献干净**：是否已剔除网页/软件手册？文内引用与文后列表是否一一对应？
- [ ] **目标期刊参数**：是否已按本次指定的目标期刊核对字数、语态、摘要长度及文献双语体例？

## 5. 改稿文件安全与排版验收门禁

1. **改稿不覆盖原稿**：对已有草稿做结构重组或批量润色前，先保留带时间戳备份或在指定副本上修改；原始数据、原始图表工程只读不覆盖。
2. **Word / LaTeX 排版核对**：
   - 表格统一采用规范**三线表**，表头含物理量与单位；
   - 数学公式保留**原生可编辑公式对象**，不把图片公式或乱码文本混入正文；
   - 统一中文字体（如宋体）与英文/数字字体（如 Times New Roman），消除中英文混排格式错乱；
   - 图题与图件、表题与表格**不跨页拆分**。
3. **逐页视觉验收**：交付最终版前，导出或打印为 PDF 并逐页检查，确认无公式截断、无图内文字遮挡、无悬空占位符；若尚留有待补图件或作者元数据，须明确标注交付阶段，不直接称为完整投稿定稿。
