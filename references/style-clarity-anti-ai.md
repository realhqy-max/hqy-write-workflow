# 语言精修与去 AI 腔指南（Style, Clarity & Anti-AI）

本清单用于起草与逐句审校阶段，确保文字符合真人高水平学术期刊表达习惯。

---

## 1. 段落衔接与清晰度原则

1. **主题句前置**：每段首句直接亮出本段核心发现、观点或任务，让读者只读每段第一句就能串起全文逻辑。
2. **旧信息 → 新信息（Old-to-New）**：
   - 句子开头承接上文已出现的已知概念或对象（旧信息）；
   - 句子末尾引入新现象、新变量或新判断（新信息）；
   - 避免连续两句各自起头、毫无过渡。
3. **去名词化（强动词原则）**：
   - 尽量使用“主语 + 具体动作”，减少“进行了……的分析”“开展了……的转换”“实现了……的对比”等冗余名词化结构。

---

## 2. 必须清除的 5 类问题表达

### 2.1 “AI 腔”目的性前缀与套话
写作时不要在每个方法步骤前刻意加“为了证明自己合理”的目的状语，也不在句尾加空洞意义：

| 应避免的 AI 腔表达 | 推荐的自然学术表达 |
|---|---|
| 为跨模型统一配对基准并消除……的影响，采用…… | 为保证不同模型在相同空间位置比较并考虑单元体积差异，采用…… |
| 为规避断层端部局部极值干扰，采用 $P_{90}$ 稳健表征…… | 近场采用体积加权 $P_{90}$ 表征较高扰动水平，以降低少数极端值影响。 |
| 以突出目标层岩性弹性参数差异，构建…… | 构建 M 与 S 模型，用于比较不同岩性弹性参数下的应力响应差异。 |
| 从而实现……可靠性 / 以确保……准确性 | 据此…… / 通过……检验结果对……的敏感性 |
| 研究结果支持按……开展……评价 / 为……提供依据 | （直接删除套话，结束于具体发现或明确适用边界） |
| ……关系仍保持 / ……排序保持 | 改写为具体事实，如“砂岩的……仍高于泥页岩” |

### 2.2 “代码翻译腔”与内部后处理黑话
禁止将脚本变量名、处理步骤黑话直接当作正文术语。首次出现必须转化为学科标准术语：
- 避免：“状态 0 / 状态 1”“父单元 / 子单元”“区段删除”“空间支持”“共同 $q$ 筛选”“加密”“降穿”“47 项闭合”。
- 替换为：“无断层背景场 / 含断层应力场”“代表性单元”“断层走向分段剔除检验”“剔除低差应力区（$q \le 1\text{ MPa}$）”“细化网格”“向下穿过阈值”。

### 2.3 长括号堆叠与多任务长句
- 一句话只承担一个主要任务（要么定义方法，要么交代样本规模，要么报告结果）。
- 除纯数学表达式、简短代号（如 `（M）`）或短单位外，**不要把多层统计信息、样本细分和补充解释连续塞进括号**，应拆成独立短句或归入表格。

### 2.4 负向框架式立论（No Negative Framing）
- 避免滥用“不是……而是……”“并非……而是……”等先树靶子再反驳的句式。
- 直接写明“是什么、由什么决定、在什么条件下成立”。

### 2.5 防御性自我拆台
- 不要在摘要末句、结论末句或图注末尾反复打补丁式自我削弱（例如突然加一句“但受限于局部段和外域变化，上述结果仍存在不确定性”）。
- 必要的限定条件**集中且平静地**写在方法口径或讨论的适用边界段，一次交代清楚即可。

## 3. 逐句审校自检问题

修改任何段落时，依次问自己四个问题：
1. **这句话拿掉，会不会影响后面的结论？**（不影响且无必要背景作用 → 删）
2. **外行或跨方向审稿人读第一遍能立刻听懂吗？**（需要反推解码 → 拆句、补全主语/对象、换标准术语）
3. **有没有把“结果”和“推测解释”混在同一句？**（混杂 → 拆开，标明证据层级）
4. **有没有为了显严谨而反复重复前文已经交代过的限定条件？**（重复 → 只保留一处最合适的位置）
